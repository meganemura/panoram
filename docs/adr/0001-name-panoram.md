# 0001. The tool is named panoram.

Date: 2026-09-10

Status: superseded by [0030](0030-rename-to-spacequery.md)

## Context

The tool gives one view of a developer's machine.
The name is the verb form of panorama.
The npm name `panorama` belongs to another tool.

## Decision

The tool is named `panoram`.
The npm package stays reserved at version `0.0.0`.
The package stays at that version until the owner authorizes publication.

## Consequences

The name identifies the query tool in the package, command, and documentation.
The reserved package prevents a name conflict during v0.
